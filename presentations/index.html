補足 ①

counter ＝ CSSが持てる唯一の「数」

枚（1個 ＝ +2 に設定）
#main { counter-reset: cookies 0; }        /* ① 0で用意する */

input:checked { counter-increment: cookies 2; }  /* ② checked 1個ごとに +2 */

#result::after { content: counter(cookies) "枚"; }  /* ③ 表示（唯一の読み出し口） */

counter は変数ではなく「いまの checked を数え直した結果」。増減の記録はどこにも残りません。だから解除すれば残高も勝手に減ります。

補足 ②

:has() ＝ 中を見て、外を変える

2つ揃うと、この箱ごと色が変わる 
.box:has(#h1:checked):has(#h2:checked) {  /* 中に checked が2つ揃ったら */
  background: skyblue;                  /* 外側の箱そのものを変える */
}

通常のセレクタは「親→子」にしか効きませんが、:has() は子の状態で親や周りを変えられます。買える判定も、群の切替も、全部これ。

補足 ③

:nth-last-child(N) ＝ 後ろからN番目

↑ ここが「後ろから3番目」（:nth-last-child(3)）
HTMLでは後に書いた要素が手前に重なる → 手前 ＝ 末尾（右端）から先に押されるので、✓は右から増えます。
input:nth-last-child(3):checked  /* 後ろから3番目が checked */

/* 後に書いた要素が手前 → 手前から押される ＝ 消費はDOM末尾から。
   だからこれは「3回以上押した」の意味になる。
   4回・5回押しても成立したまま。✓を外せば不成立に戻る */

「N枚あるか」を数える機能はないので、N回目に押される checkbox の位置を条件にしています。この列はDOMの並びのまま（右端 ＝ 末尾 ＝ 一番手前）。後ろから消費されるので、3回目で「後ろから3番目」に ✓ が入ります。

STEP 8

セレクタは Sass の再帰で全列挙する

書いたもの：再帰mixin（抜粋）

@mixin distribute-clicks(
  $base, $item, $required, $chain,
  $index: length($chain), $earned: 0, $counts: ()
) {
  @if $index < 1 {
    /* ちょうど買える境界にだけ出力 */
    #{$base}#{click-conditions($counts)} … {
      --purchase-visibility: visible;
    }
  } @else if $earned + max-earnings($chain, $index)
             >= $required {
    /* 残りを上限まで押しても届かない枝は捨てる */
    @for $clicks from 0 through … {
      @include distribute-clicks(…, $index - 1,
        $earned + $clicks * $rate);
    }
  }
}

まとめ

  • 🍪 checkbox 1個 ＝ 押した記憶。持てる情報はこれだけ。
  • 📚 100個重ねて、手前から消費 ＝ 連続クリック。
  • 🔢 残高は counter の数え直し。単価は購入の組み合わせで決まるので、群を16通り持って過去の分を守る。
  • 🧩 買える判定も切替も、:has() で「形」を見るだけ。
  • 🧨 計算はしない。全状態を先に書いておく。だから Sass で生成する。
