QUESTION 1

押した回数は、どこに残っているんでしょう？

unchecked
まだ押されていない
checked
「1回押した」という事実だけが残った

答え：checkbox 1個の checked です。

🍪 は <label>、左のチェックボックスが <input type="checkbox"> 本体。同じ1個の要素なので、cookie を押すと本物のチェックが入ります。
このゲームに変数はありません。持てる情報は checked か unchecked かの2択だけです。

QUESTION 2

1個しか押せないのに、なぜ連打できるんでしょう？

↑ 本物の checkbox 8個。右端から順にチェックが入っていきます。

答え：同じ場所に重ねて、手前から1個ずつ消費しています。

本物は 100個重なっています。後に書いた要素ほど手前に描かれるので、押せるのはいつも一番手前の1個。押されたものは脇へ飛び、次が手前に出ます。z-index も JavaScript も使っていません。

QUESTION 3

枚数は、誰が数えているんでしょう？

答え：CSS の counter() です。

押すたびに counter-increment が積み上がるだけ。JavaScript は関与していません。

QUESTION 4

「買える／買えない」は、どう判定しているんでしょう？

答え：:has() で「5個目が checked か」を見ているだけです。

数えて5と比べているのではなく、その形になっているかを見ています。5回押すと色が変わります。

QUESTION 5

買うと1回で2枚もらえるのは、なぜでしょう？

答え：押せる checkbox の群が、まるごと別の群に入れ替わるからです。

増える枚数を変えているのではなく、+2 と書いてある別の群に有効／無効が入れ替わるだけです。

QUESTION 6

では、買う前に押した分も2倍になるでしょうか？

答え：なりません。古い群の checkbox として、+1 のまま数えられ続けます。

rate-1 の checkbox は無効になっただけで DOM に残っています。だから遡って計算し直すことが起きません。

QUESTION 7

アイテムが4個に増えると、何が起きるでしょう？

0000100001000010 0001110010101001 0110010100111110 1101101101111111

答え：状態が 2⁴ ＝ 16通りに増え、その全部にCSSが要ります。

いまハイライトされている1つを選ぶために、16通りぶんのセレクタがこのスライドにも手で書いてあります。本物ではこの16通りに、さらに「どの群を何回押したか」の組み合わせが掛かります。だから style.css は 24,000行以上になります。

ネタバラシ

CSSは計算していません。全部あらかじめ書いてあるだけです。

手続き的（JavaScript なら）

// 状態は変数。押されたら「計算して」求める
let cookies = 0, rate = 1;

onClick = () => cookies += rate;
onBuy   = (item) => {
  cookies -= item.price;
  rate += 1;
};

この数行で、あらゆる残高に対応できる。実行時に計算するから。

宣言的（このゲームのCSS）

/* 「この状態のときはこう見える」を並べるだけ */
#main:has(#item1:checked)
     :has(> .rate-1 > input:nth-last-child(6):checked)
  .item2 .purchase { background: skyblue; }

/* ↑ 起こりうる状態の数だけ並んでいる */

CSSに「足す」も「比べる」もない。あるのは「この形に当てはまるか」だけ。

だから残高は「増えていく数」ではなく、いまこの瞬間の checked の並びから、毎回そのまま読み出されている結果です。
そして、いま見ているこの資料のページ送りも同じ仕掛けで動いています。

まとめ

まとめ

  • 🍪 checkbox 1個 ＝「1回押した」という記憶。持てる情報はこれだけ。
  • 📚 同じ場所に重ねて手前から消費させることで、連続クリックに見せている。
  • 🔢 枚数は counter が数えた結果。過去に押した分の単価は後から変わらない。
  • 🧩 購入可否も rate 切替も、:has() で形を見ているだけ。
  • 🧨 CSSは計算しない。起こりうる状態を全部あらかじめ宣言してある。だからSassで生成する。

この資料自体も JavaScript ゼロ。ページ送りはラジオボタン、キー操作はラジオグループの標準動作、リセットは <input type="reset"> です。
