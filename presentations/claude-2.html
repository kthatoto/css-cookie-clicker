③のレイヤーを拡大：Sassは「状態空間コンパイラ」
購入済みアイテムの集合（2^N通り）× 各rate群のクリック数の組み合わせを総当たりし、 「ちょうど購入可能になる境界」にだけ静的CSSルールを生成する（buyable-frontier / click-rate-states）。 アイテムが増えるほど、生成されるセレクタ数は組み合わせ的に増える。
@function click-conditions($click-counts) {
  $selector: "";
  @for $rate from 1 through length($click-counts) {
    $clicks: nth($click-counts, $rate);
    @if $clicks > 0 {
      $selector: $selector +
        ":has(> .click-group.rate-#{$rate}
           > input:nth-last-child(#{$clicks}):checked)";
    }
  }
  @return $selector;
}
// buyable-frontier / buyable-states / click-rate-states が
// これを「購入済み集合 × 各rateのクリック数」で再帰的に総当たりし、
// 境界だけに --purchase-* を割り当てるCSSルールを吐き出す

① DOM100個重ねたcheckbox（rate群）・item群「何回クリックしたか」「何を買ったか」を checked という状態で記憶する実体
③ Sass生成CSS:has() と :nth-last-child() の総当たりセレクタ①の状態を検知し、購入可否の表示・rateの可視化切り替えを静的に発火させる
② Countercounter-increment の積み上げ③が発火させた増減を cookies 枚数として画面に表示する

過去にrate-1で消費したクリックは、rate-2に切り替わった後も rate-1群のcheckboxとしてDOMに残り続け、 ①③②のどの層で見ても価値は「1」のまま変わらない。
